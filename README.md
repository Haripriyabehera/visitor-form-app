# Visitor Registration Form (React App)

A simple React app that allows society visitors to register their visit. Built with functional components, Context API, and localStorage.

## Features

- Full Name, Flat Number, Purpose, and Mobile Number input
- 10-digit validation for mobile number
- Purpose dropdown (Delivery, Guest, Maintenance, Other)
- Shows visitor data below form after submission
- Stores logs in localStorage
- Basic responsive design
